# Brainstorming del equipo

Aquí guardamos el resumen de lo que vamos hablando con Claude, para que todo el equipo tenga lo mismo. Claude actualiza esta carpeta cada vez que avanzamos. Los chats de Claude no se sincronizan solos: lo que hay aquí son resúmenes.

| Archivo | Qué contiene |
|---|---|
| [idea.md](idea.md) | **La idea actual, a fondo.** Cómo funciona paso a paso, qué hemos descartado dentro de ella y qué falta decidir. Base para el MVP |
| [estado-actual.md](estado-actual.md) | **Empieza por aquí.** Dónde estamos, qué ideas hay sobre la mesa y qué falta decidir |
| [decisiones.md](decisiones.md) | Lo que ya está decidido y lo que se ha descartado, con fecha y motivo |
| [notas-del-jurado.md](notas-del-jurado.md) | Cada idea puntuada con la rúbrica del reto y sus puntos de fuga |
| [investigacion-profunda.md](investigacion-profunda.md) | Búsqueda en la web del 13 nov: qué existe ya y qué dice la evidencia, con enlaces |
| [investigacion-internacional.md](investigacion-internacional.md) | Cómo explican el dinero en otros países (14 referentes) |
| [psicologia-enganche.md](psicologia-enganche.md) | Ideas de psicología y enganche |

Avisos:
- Las puntuaciones son estimaciones de Claude con la rúbrica del README, no notas reales del jurado.
- Los referentes de otros países están citados de memoria. Hay que comprobarlos antes de usarlos en el pitch.
- Las cifras de las familias salen de `cases/`. Donde hay un cálculo nuestro, se indica.
- Nunca se guardan aquí claves ni tokens.
